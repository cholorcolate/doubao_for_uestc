# doubao_for_uestc

> 项目状态：数据爬取完成（2026-09-22）

## 项目定位

面向**电子科技大学（UESTC）**师生/校友的智能体网站：让 AI 真正"懂成电"——能准确回答校园政策、教务流程、生活服务、考研保研等校园专属问题，并聚合常用校园信息与工具，而不是只会泛泛而谈的通用问答。

## 核心问题（要解决什么）

通用大模型不了解校园细节：校历安排、教务系统操作、选课/退课规则、奖学金与保研政策、校区班车时刻、场馆预约、校内办事流程等，答案经常是"大概、可能"，无法直接落地。本项目用**专属知识库 + 智能问答 + 工具聚合**补上这一环。

## 初步思路（待细化）

1. **数据层**：爬取并持续更新校内公开信息源（学校官网、教务处、学工部、研究生院、后勤、校医院等），清洗后构建结构化知识库 + 向量库（RAG）。
2. **智能层**：大模型 + RAG 检索增强，回答时标注信息出处与时效；对无把握的问题明确说"不知道"，而不是编造。
3. **应用层**：Web 网站，核心模块包括——
   - 智能问答（校园政策 / 办事流程 / 生活服务）
   - 信息聚合（通知公告、讲座、竞赛、招聘）
   - 校园工具（校历、校车时刻、课表/校历查询、场馆与教室信息）
   - 个性化（登录后可订阅关注的通知 / 收藏）
4. **差异化**：不只做"问答机器人"，而是校园信息的入口，答案可溯源、工具可直接用。

## 技术栈（初步）

- 前端：Web 网页（后续定）
- 后端：Python（FastAPI 等）
- AI：RAG（向量检索）
- 数据：爬虫（合规采集公开信息）+ 结构化存储 + 向量数据库

## 模型策略（2026-09-17 确认）

> **所有模型能力一律调用云 API，本地不部署任何模型，零 GPU 需求。**

| 能力 | 选型（API） | 说明 |
|---|---|---|
| 对话生成 LLM | 豆包（火山方舟）为主，DeepSeek-V4 备选 | 豆包生态、有免费额度；DeepSeek-V4 便宜、数学/推理强 |
| 向量化 Embedding | 豆包 doubao-embedding 系列（火山方舟） | 支持中英文，版本需固定 |
| 重排 Rerank | 硅基流动 SiliconCloud（Qwen3-Reranker 或 bge-reranker） | 在线 API，价格极低 |
| 向量数据库 | 本地开源（Chroma/Milvus）或云托管（VikingDB） | 非模型，不占 GPU，可选 |

要点：模型版本固定、API Key 走环境变量/密钥管理、注意各服务限流与价格口径（DeepSeek 有峰谷定价）。

### 快速开始

#### 1. 安装依赖

```bash
cd crawler
pip install -r requirements.txt
```

#### 2. 下载数据

从 [Releases](https://github.com/cholorcolate/doubao_for_uestc/releases) 下载压缩包，解压到本地目录。

#### 3. 使用爬虫

**匿名抓取（公开内容）：**
```bash
python uestc_bbs_crawler.py --no-login
```

**登录抓取（完整内容）：**
```bash
# 方式1：使用环境变量
export BBS_USER="你的用户名"
export BBS_PASS="你的密码"
python uestc_bbs_crawler.py

# 方式2：直接运行，按提示输入
python uestc_bbs_crawler.py
```

**全量抓取（所有板块所有页面）：**
```bash
export BBS_USER="你的用户名"
export BBS_PASS="你的密码"
export BBS_MODE="7"
python uestc_bbs_crawler.py --data-dir ./data --max-pages 100
```

**批量抓取正文（断点续传）：**
```bash
export BBS_USER="你的用户名"
export BBS_PASS="你的密码"
export BBS_MODE="5"
python uestc_bbs_crawler.py --data-dir ./data
```

### 爬虫模式说明

| 模式 | 说明 |
|------|------|
| 1 | 爬取所有板块和帖子（每板块前5页，前10个主题正文） |
| 2 | 爬取指定板块（需输入板块ID） |
| 3 | 爬取指定帖子（需输入帖子ID） |
| 4 | 只爬取板块列表 |
| 5 | 批量抓取已发现帖子的完整正文（断点续传） |
| 6 | 依据现有索引重抓全部主题正文（可选覆盖） |
| **7** | **全量抓取（推荐）：登录后抓取所有板块所有页面+所有主题正文** |

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--data-dir` | 数据输出目录 | `C:\soft\opencode_download\uestc-public` |
| `--interval` | 最小请求间隔（秒） | 1.0 |
| `--max-pages` | 每个板块最大抓取页数 | 100 |
| `--max-threads` | 每个板块最大抓取主题数（0=全部） | 0 |
| `--force` | 重抓已有正文文件 | false |
| `--no-login` | 匿名抓取公开内容 | false |

### 注意事项

1. **合规使用**：本爬虫仅供学习和研究使用，请遵守论坛 robots.txt 规则
2. **控制频率**：默认请求间隔 1 秒，请勿设置过小以免对服务器造成压力
3. **登录账号**：使用自己的论坛账号登录，不要使用他人账号
4. **数据存储**：爬取的数据体积较大（约 845 MB），请确保磁盘空间充足
5. **断点续传**：支持断点续传，中断后可继续抓取

### 常见问题

**Q: 登录失败怎么办？**
A: 检查用户名密码是否正确，如果论坛启用验证码可能需要手动处理。

**Q: 爬取速度太慢？**
A: 可以减小 `--interval` 的值，但建议不低于 0.3 秒。

**Q: 如何爬取特定板块？**
A: 使用模式 2，输入板块ID（fid）。可在论坛页面 URL 中找到。

**Q: 数据保存在哪里？**
A: 默认保存在 `--data-dir` 指定的目录，程序运行目录下的 `data` 文件夹。
